## Full description

SynStudios helps animators and game teams validate animation work before committing to full production budgets.

**2D sprite preview**
- Horizontal strip playback compatible with Godot AnimationLoader conventions
- Upload PNG sprite sheets and scrub frame-accurate walk cycles, idles, and attacks
- Pixel-perfect nearest-neighbor rendering

**3D animation preview**
- React Three Fiber rig preview with orbit camera
- Procedural demo rig included; glTF pipeline ready

**30-second trial runs**
- Capped preview sessions with FPS metrics
- Pass/fail gate for smooth mobile performance
- Split view for 2D + 3D composite cutscene trials

**Built for mobile**
- Black-and-white professional UI
- Works offline for core preview features
- Optional live sync for team review sessions

SynStudios — validate motion, timing, and performance before you ship.
